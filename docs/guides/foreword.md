# Guides

The Cloud Robotics Hub guides collect practical advice and best practices for
common cloud robotics problems. They are living documents built from working
group discussions, guest talks, community feedback, and real deployments.

Available guides:

- [Logging and Observability](/docs/guides/logging-and-observability)

:::tip

These guides are works in progress. If you have experience to contribute,
please [create an issue](https://github.com/cloudroboticshub/cloudroboticshub.github.io/issues/new)
so the working group can review it.

:::
